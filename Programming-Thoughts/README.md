# Programming Thoughts Notes
Complete English notes for programming thoughts, covering computer university curriculum, enterprise development standards and technical interview core knowledge.
Suitable for CS students, junior developers and interview candidates.

## 📖 Introduction
Most beginners only focus on grammar, framework and tool usage, but ignore the underlying programming thinking.
This repository systematically arranges the complete programming thought system from shallow to deep, helping developers:
- Get rid of fragmented coding habits
- Build standardized software design thinking
- Write low-coupling, high-maintainability code
- Master high-frequency interview design questions
- Avoid common detours in early programming learning

All articles are written in **simple & professional English**, with mixed layout of paragraphs, lists and tables, conforming to real handwritten note style, friendly for Git reading and daily review.
